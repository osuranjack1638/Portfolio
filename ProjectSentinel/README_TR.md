# Project Sentinel
Project Sentinel belirttiğiniz objeleri belirli değerlerle test ederek bir sorun var mı diye arayan bir Roblox sistemi.

---

## Neden Project Sentinel?
Çünkü oyununuzda herhangi bir problem var mı yok mu bilmediğiniz zamanlarda Project Sentinel ile neden sorun olduğunu öğrenip daha oyunda kullanmadan düzeltebilirsiniz.

---

## Test Edilebilen Objeler Ve Test İçin Kullanılan Değerler
Project Sentinel şu objeleri test edebilir:
- function
- Object Oriented Programming(OOP) objeleri
- table
- BindableEvent
- RemoteEvent

Project Sentinel objeleri şu veri türleriyle test eder:
- Number
- Float
- String
- Boolean
- Instance
- Vector3
- Vector2
- CFrame
- Color3
- Table
- Ve config dosyasından ekleyebileceğiniz bütün değerler!

---

## Nasıl Kurulur?
1. **ReplicatedStorage** altında `ProjectSentinel` isimli bir `ModuleScript` yaratın.
2. **ProjectSentinel**  altında `Config` isimli bir `ModuleScript` yaratın.
3. Modüllerin kodlarını dosyalara yapıştırın.
4. Fonksiyonlarınızı ve RemoteEvent vb. objeleri test etmek için kullanıma hazır!

---

## Extra
Kullanımdan sonra modülü ServerStorage içerisine koymanız önerilir. Aksi takdirde hile kullanan oyuncular modülü kullanarak oyununuzu kastırabilir.
