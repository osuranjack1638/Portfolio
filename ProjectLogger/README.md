# Project Logger
Project Logger is a roblox system that can track functions and log errors/warnings.

---

## Why Use Project Logger?
You should use Project Logger because debugging/logging can become hell if done wrong. Project Logger makes debugging/logging much easier for you.

---

## Handled Tracking Types
- function

## The Module Tracks These Values
- Amounts Called
- The Amount Of Time It Took To Run Last Time
- The Amount Of Failures
- The Success Rate
- Fastest, Slowest, Total And Average Run Time

---

## How To Setup?
1. Create a `ModuleScript` named `ProjectLogger` inside **ReplicatedStorage**.
2. Create a `ModuleScript` named `Config` inside the **ProjectLogger** module.
3. Paste the contents of the modules.
4. Use it to log/debug whatever you need.
